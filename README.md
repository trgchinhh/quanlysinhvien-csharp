# Quan ly sinh vien C#
Dự án nhỏ về chương trình quản lý sinh viên vận hành với các tính năng cơ bản như thêm, sửa, xóa, thống kê. Mục đích dự án luyện C# cơ bản làm chương trình Console (CLI) thông thạo cú pháp và làm quen OOP của ngôn ngữ. Hiện tại chương trình này demo cơ bản chứ không đầy đủ tính năng về code, chỉ phù hợp tham khảo.
